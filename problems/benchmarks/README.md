# Benchmark Problems

This directory stores reusable benchmark inputs for Cofola experiments,
generated by `scripts/benchmarks/run.py`.

Three suites:

- `real/` — real-world combinatorics problems drawn from
  `problems/real/corpus.json`.
- `growing/` — parameterised scaling families (`mathcounts`, `fourletter`,
  `tvs`, `workers`, `banana`), generated by default at domain sizes
  `5, 10, ..., 100`.
- `synthetic/` — fixed materialized synthetic `.cfl` cases and their manifest.

`manifest.json` and `manifest.csv` record case metadata: id, suite, expected
answer when available, tags, source, relative `.cfl` path, and program
SHA-256 hashes for reproducibility.

Generated experiment outputs (`results.csv`, `summary.csv`, plots) belong
under `check-points/`.
